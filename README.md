# Biblioteca-Infantil
La biblioteca infantil es un espacio acogedor, colorido y lleno de imaginación, creado especialmente para que los niños disfruten de la lectura y aprendan de una manera divertida. Cuenta con libros de cuentos, aventuras, animales, ciencia y fantasía, organizados de forma sencilla para que puedan encontrarlos fácilmente.
